# Relentless Market - Open Source Trading Client

A professional-grade, open-source trading client for macOS that connects to Alpaca for trade execution. Built with Swift and SwiftUI, featuring institutional-grade analytics and real-time market intelligence.

## Features

- **macOS Native**: Optimized for Apple Silicon with native performance
- **Alpaca Integration**: Seamless connection to your Alpaca brokerage account
- **Real-time Analytics**: Live market data, charts, and institutional-grade indicators
- **Advanced Trading Tools**: Professional order management and execution algorithms
- **Open Source**: 100% transparent codebase with no vendor lock-in
- **Professional UI**: Clean, modern interface designed for serious traders

## Requirements

- macOS 12.0+ (Monterey or later)
- Active Alpaca trading account
- Stable internet connection

## Installation

1. Clone this repository
2. Open in Xcode 14+
3. Build and run

## Usage

1. Connect your Alpaca account
2. Access real-time market data
3. Execute trades with advanced order types
4. Monitor portfolio performance
5. Use professional analytics tools
