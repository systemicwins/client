# Relentless Market - Professional Trading Platform

A comprehensive, open-source trading platform for macOS that connects to Alpaca for trade execution. Built with Swift and SwiftUI, featuring institutional-grade analytics, real-time market intelligence, and advanced trading tools.

## Features

- **macOS Native**: Optimized for Apple Silicon with native performance
- **Alpaca Integration**: Seamless connection to your Alpaca brokerage account
- **Real-time Analytics**: Live market data, charts, and institutional-grade indicators
- **Advanced Trading Tools**: Professional order management and execution algorithms
- **Market Scanning**: Automated gapper detection and stock screening
- **AI-Powered Insights**: Machine learning models for market analysis
- **SEC Filing Analysis**: Automated analysis of SEC filings and company data
- **Open Source**: 100% transparent codebase with no vendor lock-in
- **Professional UI**: Clean, modern interface designed for serious traders

## Requirements

- macOS 12.0+ (Monterey or later)
- Active Alpaca trading account
- Stable internet connection
- 32GB+ RAM recommended for optimal performance

## Installation

1. Clone this repository
2. Open in Xcode 14+
3. Build and run

## Usage

1. Connect your Alpaca account
2. Access real-time market data and analytics
3. Use the stock scanner to find trading opportunities
4. Execute trades with advanced order types
5. Monitor portfolio performance with detailed analytics
6. Analyze SEC filings and company fundamentals

## Architecture

The platform is built with a modular architecture:

- **TradingPlatform**: Main application with comprehensive trading features
- **TestApp**: Development testing interface
- **Shared Services**: Core functionality for API communication, data processing, and UI components
